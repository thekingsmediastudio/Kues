# Kues Logo Kit

The logo lockups use the existing friendly green cloud mascot. The product name is Kues; the mascot artwork has not been redesigned. Agent avatars are separate object characters and do not replace the cloud logo.

## Deliverables
- `kues-logo-horizontal-dark.svg/.png`: transparent horizontal lockup, light wordmark for dark surfaces.
- `kues-logo-horizontal-light.svg/.png`: transparent lockup, dark wordmark for light surfaces.
- `kues-logo-monochrome.svg/.png`: single-ink lockup.
- `kues-icon.svg`: transparent green cloud mascot icon.
- `kues-icon-monochrome.svg` and `kues-icon-monochrome-1024.png`: one-ink icon.
- `kues-app-icon.svg`, `kues-app-icon-1024.png`, `kues-app-icon-512.png`, `kues-app-icon-192.png`: square charcoal app tile.
- `kues-icon-transparent-1024.png`: transparent high-resolution mascot icon.
- `kues-favicon-64.png`, `kues-favicon-32.png`, `kues-favicon-16.png`: favicon exports.
- `kues-logo-approved-reference.png` and `kues-icon-approved-reference.png`: reference previews.
- `Kues_Logo_Kit_Overview.png`: visual asset board.

## Palette
Charcoal `#111113`; emerald `#32D583`; face `#173026`; cheek `#F39B91`; light wordmark `#F3F3F5`; light-surface wordmark `#17181B`.

## Agent avatar object icons
Ten friendly flat SVG agent icons are in `avatars/kues-agent-avatar-{bulb,laptop,shield,cart,car,parcel,magnifier,tag,wallet,van}.svg`. The 10 types are bulb, laptop, shield, shopping cart, car, parcel, magnifier, price tag, wallet, and delivery van. The wallet, car, and delivery van silhouettes were refined for clearer recognition and more balanced facial details at small sizes. They are used in onboarding and the desktop app; colors can be adapted by the UI. The current masters use black outlines, eyes, and facial line details. The Kues green cloud remains the product mark.

Animated SVG preview board: `Kues_Agent_Avatars_Overview.html`. The standalone vector files are bundled in `Kues_Agent_Avatars_2026-10-25.zip`.
